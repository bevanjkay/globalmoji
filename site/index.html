Emoji, GIFs, kaomoji

Search 1,900+ emoji by name, keyword or Slack/GitHub shortcode. ⇥ switches to GIPHY GIF search or a curated set of ASCII faces like ¯\_(ツ)_/¯.

Works everywhere you type

Slack, Mail, Notes, browsers, terminals — the picker appears beside your caret and inserts inline. Choose which apps it’s active in.

Open source, no account

MIT licensed Swift. Nothing leaves your Mac except GIF searches. Signed with Developer ID and notarised by Apple.

Install

brew install --cask bevanjkay/tap/globalmoji

or download the DMG above and drag Globalmoji to Applications. On first launch, grant Input Monitoring and Accessibility — that’s how it sees the : and inserts your pick.
